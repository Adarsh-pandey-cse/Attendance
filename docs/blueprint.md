# **App Name**: AttendX

## Core Features:

- Time-based Greeting: Greet user based on current time of day.
- Subject Management: Add, edit, and manage subjects with details like name, total classes, and presents.
- Attendance Calculation: Dynamically calculate attendance percentage and classes needed/can be skipped to reach target.
- Attendance History: Calendar-style history view of attendance records with timestamps.
- Target Notification: Use a tool, backed by generative AI, to trigger notifications (if any) when attendance nears or falls below the target. 
- Profile Customization: Allow users to add a display name.
- Developer Info: Dedicated section with developer details: Adarsh Pandey, adarshpandey880079@gmail.com

## Style Guidelines:

- Primary color: Emerald green (#3CB371) for a fresh, academic feel.
- Background color: Deep navy blue (#1A2233) with soft neumorphic/glassmorphism effects.
- Accent color: Aqua/cyan (#00FFFF) for highlights and interactive elements.
- Body and headline font: 'Inter', a sans-serif for a modern, neutral feel.
- Implement a responsive layout with a 3D effect using soft shadows and highlighted cards.
- Use clean, professional icons representing subjects and attendance status.
- Tasteful animations and transitions for a premium touch-friendly experience.
